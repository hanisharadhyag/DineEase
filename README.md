# DineEase — Restaurant Dine-In Reservation Web App

A clean, modern, and simple academic React + Supabase project built with **React**, **Vite**, and **Plain CSS**.

---

## 🌟 Features

- **Home Page (`/`)**:
  - Hero section with clear tagline (*"Find your table. Enjoy your meal."*)
  - "Featured Restaurants" section previewing top dining choices.
  - "How It Works" 3-step guide: Choose a restaurant &rarr; Book your table &rarr; Enjoy your meal.
  - Quick action buttons to explore restaurants or jump straight into booking.

- **Restaurants Page (`/restaurants`)**:
  - Browse 8 premier restaurants (Karavalli, Farmlore, LUPA, Rim Naam, Shiro Bengaluru, Bombay Brasserie, The 13th Floor, Spice Terrace) fetched from Supabase.
  - Reusable `RestaurantCard.jsx` showing high-resolution imagery, cuisine badges, rating stars, location, description, and action buttons.

- **Restaurant Details (`/restaurant/:id`)**:
  - Comprehensive view of individual restaurant details.
  - Direct "Book a Table" call-to-action that pre-selects the restaurant on the booking form.

- **Booking Form (`/booking`)**:
  - Controlled inputs managed using React `useState`.
  - Fields: Restaurant (dropdown), Customer Name, Phone Number, Date (future dates enforced), Time Slot, Number of Guests, Seating Table, and Special Requests.
  - Real-time client-side validation with helpful error messages.
  - Performs **Supabase INSERT** on submission.
  - Interactive **Reservation Confirmed** confirmation card with booking summary and direct link to reservations.

- **My Reservations (`/reservations`)**:
  - Live **Supabase SELECT** query fetching all confirmed reservations.
  - Formatted booking cards showing restaurant, guest details, date, time, table, and special requests.
  - Refresh button and empty state handling.

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite, JavaScript
- **Routing**: React Router DOM v7
- **Database / Backend**: Supabase (PostgreSQL) via `@supabase/supabase-js`
- **Icons**: `lucide-react`

## 🗄️ Supabase Database Schema

### 1. `restaurants` Table
```sql
CREATE TABLE IF NOT EXISTS restaurants (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  cuisine TEXT NOT NULL,
  location TEXT NOT NULL,
  rating NUMERIC(2, 1) NOT NULL,
  image_url TEXT NOT NULL,
  description TEXT NOT NULL
);
```

### 2. `reservations` Table
```sql
CREATE TABLE IF NOT EXISTS reservations (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  restaurant TEXT NOT NULL,
  customer_name TEXT NOT NULL,
  phone TEXT NOT NULL,
  date DATE NOT NULL,
  time TEXT NOT NULL,
  guests INT NOT NULL,
  table_number TEXT NOT NULL,
  special_request TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 3. Row Level Security (RLS) Policies
```sql
ALTER TABLE restaurants ENABLE ROW LEVEL SECURITY;
ALTER TABLE reservations ENABLE ROW LEVEL SECURITY;

-- Allow public read access to restaurants
CREATE POLICY "Allow public read access on restaurants"
ON restaurants FOR SELECT TO anon, authenticated
USING (true);

-- Allow public read access to reservations
CREATE POLICY "Allow public read access on reservations"
ON reservations FOR SELECT TO anon, authenticated
USING (true);

-- Allow public insert access on reservations
CREATE POLICY "Allow public insert access on reservations"
ON reservations FOR INSERT TO anon, authenticated
WITH CHECK (true);
```

## 🚀 Running the Project Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Environment Variables**:
   Ensure `.env` contains your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=https://dexqbqqgtjcjwjapvjxj.supabase.co
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

3. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Production Build**:
   ```bash
   npm run build
   ```

## 🎓 Academic Viva Highlights

- **React Components**: Modular components organized into reusable layout (`Navbar`), UI widgets (`RestaurantCard`), and page views (`Home`, `Restaurants`, `RestaurantDetails`, `Booking`, `Reservations`).
- **React Router**: Client-side navigation (`BrowserRouter`, `Routes`, `Route`, `Link`, `NavLink`, `useParams`, `useNavigate`, `useSearchParams`).
- **Props**: Passing restaurant objects into `RestaurantCard` and handling dynamic parameters.
- **useState**: Managing form state, validation error state, loading state, and submission confirmation state.
- **useEffect**: Fetching restaurants and reservations on component mount.
- **Controlled Form**: Two-way data binding with `value` and `onChange` handlers for all form inputs.
- **Validation**: Client-side validation ensuring required fields, valid phone numbers, guest count boundaries, and future date selections before submitting.
- **Supabase Integration**:
  - `supabase.from('reservations').insert([...])` for booking creation.
  - `supabase.from('reservations').select('*')` for fetching reservations.
  - `supabase.from('restaurants').select('*')` for catalog display.
